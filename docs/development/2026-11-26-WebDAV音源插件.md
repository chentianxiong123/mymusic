# 2026-11-26 WebDAV 音源插件（零编译拖文件）

## 背景

参考 musicxx（拟声）的云盘设计：它用 WebDAV 一个入口覆盖坚果云/阿里云盘/alist 转换的任意云盘，不逐个硬对接私有 API。这个思路跟我们"零编译拖文件插件"一致，照此做一个纯 JS WebDAV 音源插件。

## 实现

插件：`mygo/plugins/webdav/plugin.js`（已同步到 `~/.config/mymusic-mygo/plugins/`）

- **搜索**：`PROPFIND Depth:1` 递归列目录（限深 6 层 + 2000 条防误配拉爆）→ 解析 multistatus XML（前缀无关，标签本地名匹配）→ 按扩展名筛音频 → 文件名匹配关键词 → 本地切片分页
- **total**：真实匹配总数（PROPFIND 拉全量后切片），分页按 `total / size` 严格对齐
- **取流**：文件 URL 直链，basic 凭据内嵌进 URL（音频播放器不会带 header）
- **设置**：服务器地址 / 用户名 / 密码 / 音乐目录 / 搜索条数

### 路径解析的坑（实测）

WebDAV 的 `href` 有三种形态：完整 URL / 绝对路径（`/dav/xxx`，已含 base path）/ 相对路径。绝对路径必须以**服务器根**为基准拼（`http://host + /dav/xxx`），不能再拼 base（会得到 `/dav/dav/xxx` 导致根目录自我递归 13 次）。

## 架构扩展：hostSettings

JS 插件的 `host.http` 有 `allowedHosts` 静态白名单（meta 声明），WebDAV 服务器地址是用户自填的、不固定。

新增契约：`meta.hostSettings: ["server_url"]` —— 声明的设置项里填的 URL host 自动放行。

- 沙箱仍有效：只放行用户自己填的那一个 host，不是全放开
- 实现：`jsHost.hostAllowed()` 在静态白名单之外，读 `hostSettings` 声明的设置项，parse URL 取 hostname 匹配
- 测试：`TestHostAllowed_HostSettings`（填了放行、未填拒绝、其它 host 仍拒、静态白名单仍有效）

## 设计边界

- 不逐云盘私有 API（阿里/百度/115）：协议易变、登录态复杂，收益不如 WebDAV + alist
- 不做自建云盘服务端：我们是播放器不是云盘服务商
- WebDAV 搜索是"拉全量本地切片"，大盘（几千首）每次翻页都 PROPFIND——可接受（本地/NAS 快），但远端慢 WebDAV 可能卡；后续若需要可加内存缓存（不落盘）

## 后续：目录列表缓存（同日）

WebDAV 每次翻页/换关键词原本都要重新 PROPFIND 全量，远端慢服务器会卡。加内存缓存：

- `dirCache = { key, files, at }` —— JS 全局变量（VM 持久，跨 search 调用保留），不落盘
- key = `server_url + "|" + music_path`（服务器/目录变了自动失效）
- TTL = 5 分钟（`host.now()` 毫秒）
- 搜索词变化**不失效**——过滤是本地做的，缓存的是原始文件列表
- 并发安全：最坏情况是偶发重复拉一次（幂等无害），不引入 JS 层锁

测试：`TestWebDAVPluginSearch` 加 PROPFIND 计数断言——第二次搜索不发请求。

## 2026-11-26 补充：uiScale 约定统一（图标按钮 Framework 契约）

发现"词"按钮比旁边图标小的根因不是字体比例，而是框架约定混乱：
- `iconButton2`/`icon`/`lyricToggleButton`：size 是逻辑像素、内部乘 uiScale
- `playCircle`/`playIconButton`/`coverTagged`/`heartButton`：有的内部不乘、有的调用处再乘（双重缩放）

统一为：**所有 xxxButton(size) 的 size 都是逻辑像素，函数内部统一乘 uiScale，调用处不再乘**。
- 修 `playCircle`/`playIconButton`/`coverTagged` 内部乘
- 修 `widget.go` 调用处 `32*uiScale`/`26*uiScale` 双重缩放
- 结构性测试 `TestSizeContractNoRawSize` 防止再出现裸 `Size(size, size)`
- HiDPI 测试 `TestButtonsScaleConsistently` 验证各按钮同尺度
