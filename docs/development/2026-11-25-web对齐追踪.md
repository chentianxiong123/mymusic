# Web / wails3 与 mygo native 特性对齐追踪

## 架构关系（先搞清楚再对齐）

| 线 | 壳 | 业务后端 | UI |
|---|---|---|---|
| mygo native | MyGo 窗口 + `-tags native` | mygo 自己的 app（插件系统 + playback 核心） | Go UI（ui.*） |
| mygo web（无 tag） | MyGo 窗口 + `app://localhost` | `server.New()` | htmx 模板 + assets/*.js |
| wails3 | Wails3 WebView + HTTP 端口 | `server.New()`（同 web） | 同一套 htmx UI |

**结论**：web 和 wails3 业务完全一样（都是 `server.New()`），差异只在壳。
对齐 web  = 对齐 wails3。mygo native 的新特性不能盲搬——有些是 Go UI 专属（插件页、日志查看器、歌词绑定弹窗）。

### 本轮已对齐（2026-11-25）

- [x] **删掉 MyGoOutput 老取流兜底路径**：1.2.5 后只有 Supplier 一条路径；
  `Play()` 入口补默认 Source=bilibili（老持久化数据安全）。
- [x] **缓存上限确认弹窗**：web 所有档位都弹确认；去 2GB 档、加自定义档（prompt 输入 MB）。
- [x] **搜索历史样式**：单行横滑 + hover 悬浮箭头（对齐 native 最终形态）。
- [x] **外壳导航标签**：搜索→来源、投屏→目标、收藏夹→收藏（桌面+移动）。
- [x] **移动侧滑面板**：右侧浮层 + ≤50% 窗宽（对齐 native）。
- [x] **最近播放导航入口**：web 后端已有 `/hx/recent`，补桌面+移动链接。
- [x] **队列页最近播放横滑**：grid → 单行横滑 + hover 悬浮箭头（对齐 native）。
- [x] **静音不持久化**：web `volMuted` 是 JS 变量不写 localStorage（已对齐，无需改）。

  其它源 400，mygo 插件宿主用自己的端点覆盖）。

## 追加：精致弹窗组件（2026-11-25）

- [x] **统一 Overlay 弹窗 `dialog.js`**：替代浏览器原生 `window.prompt/confirm`。
  响应式（窄屏留 16px、max-height 90vh）、点背景/取消关闭、回车确认、Esc 关闭。
  `hcDialog.confirm/prompt` 支持回调 + Promise（await）两种用法。
  - 歌单新建/重命名 → hcDialog.prompt
  - 收藏取消确认 → hcDialog.confirm（fav.js 改 async）
  - 歌曲/歌词缓存上限输入 + 确认 → hcDialog.prompt/confirm
  - 清空类 confirm 暂保留原生（同步流程，改动风险大）

## 结论

低风险 + 暂缓项全部对齐。剩余都是架构差异（插件系统/扫码登录/日志查看器/蓝牙），
追踪表已逐项标"不做+为什么"，不再无限扩张。

## 不做的（明确边界）

- 插件系统 / 扫码登录 / 歌词绑定弹窗 / 日志查看器：native 专属 Go UI 能力，
  web 是 htmx + 浏览器，硬搬等于重写整个前端，违背"省资源/复用"原则。
- web/wails 的更新机制跟 mygo 不同，不强求。

## 维护纪律

- 每次 mygo native 加特性，回来更新本表（对齐/不对齐/为什么）。
- 对齐 = 同一份代码复用（主线 `server.New()` / assets），不是复制粘贴。
