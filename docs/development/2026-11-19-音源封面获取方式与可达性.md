# 音源封面获取方式与可达性（实测）

> 日期：2026-11-19 ｜ 项目：mymusic/mygo ｜ 场景：音源插件需要封面（搜索列表 + 播放）
> 结论均为本机实测（网易云 200 验证），非猜测。

---

## 1. 网易云封面（关键发现）

**搜索接口 `/api/search/get/web` 不返回 `album.picUrl`**（只给 `album.picId` + 歌手图 `artists[].img1v1Url`）。
所以"从搜索拿封面"不能写 `s.album.picUrl`——那是**空**。

| 封面 | 来源 | 实测 |
|---|---|---|
| 歌手图 | 搜索接口直接给 `artists[0].img1v1Url` | ✅ HTTP 200（PNG 640x420，149KB） |
| 专辑封面（真封面） | `song/detail` 接口返回 `songs[].album.picUrl` | ✅ HTTP 200（JPEG 980x1400，180KB） |

**修复**（`plugins/netease/plugin.js`）：搜索用**歌手图兜底**（`img1v1Url`，可达 200），播放时可调 `song/detail` 补高清专辑封面。

**注意**：网易云封面 CDN（`p3/p4.music.126.net`）**可裸拉**（无 Referer/Cookie 防盗链），返回 `image/jpeg|png`。

## 2. 各音源封面来源（搜索列表）

| 音源 | 封面来源 | 说明 |
|---|---|---|
| 网易云 | `artists[0].img1v1Url`（歌手图） | 搜索接口无 `album.picUrl`；`song/detail` 补专辑封面 |
| QQ 音乐 | `album.mid` → 拼 `https://y.gtimg.cn/music/photo_new/T002R300x300M000{album.mid}.jpg` | 搜索返回 `album.mid`，封面 URL 需拼 |
| 酷狗 | `pic` 字段 | 搜索直接给封面 URL |
| 酷我 | `pic` 字段 | 搜索直接给封面 URL |
| 咪咕 | `cover` 字段 | 搜索直接给封面 URL |

## 3. 通用建议（音源插件写封面）

1. **搜索列表**用轻量封面（网易云歌手图 / QQ 300x300 / 酷狗·酷我·咪咕 `pic`·`cover`），不阻塞搜索。
2. **播放时**可选补高清（网易云 `song/detail` 的 `album.picUrl`；QQ 可用更大尺寸拼 `T002R500x500`）。
3. 封面 URL **一般可裸拉**（音源 CDN 少防盗链）；若个别防盗链，用 `host.http` 带 Referer。
4. JS 插件封面对接：`search()` 返回 `songs[].cover`（字符串 URL），宿主 `Song.Cover` 直接透传，UI 用图。
