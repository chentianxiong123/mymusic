# 播放统计口径调研（2026-11-25）

## 调研结果（含更正）

| 软件 | 统计口径 | 来源 |
|---|---|---|
| **QQ音乐「最近播放」** | 每首歌显示播放次数；**单曲重复播放、暂停后再播都会 +1**（累计，不清记录不归零）；清空记录才清零 | [有味呀](https://www.youweiya.com/html/baike/w3y7unhntn.html) |
| **网易云「听歌排行」** | **按播放次数排序，反复听叠加**；一周/所有时间两个榜；有门槛：完整播放才算、频繁切歌（听一半）不算；离线听联网后补记 | [百度经验](https://jingyan.baidu.com/article/cd4c2979471bd3756f6e6068.html) |
| **网易云「等级听歌量」** | 唯一例外：单首要听满 >60 秒才算 1 首，**同一首听 N 次仍算 1 首**（去重），每天上限 300 首 | [网易云官方 FAQ](https://music.163.com/topic?id=199001) |
| **Spotify stream** | 官方明确：单曲循环每次听满 30 秒**都算一次 stream** | [Spotify Community 官方回复](https://community.spotify.com/t5/Other-Podcasts-Partners-etc/Spotify-streams/td-p/5005815) |
| **iTunes Play Count** | 每首歌播到结尾 Play Count +1，同时更新最后播放时间 | [Macworld](https://www.macworld.com/article/199322/itunes_playcount.html) |
| **Last.fm scrobble** | 听满 30 秒或歌曲一半才计一次 | [Last.fm API](https://www.last.fm/api/scrobbling) |
| 各平台年度报告 | 有总次数/总时长，但属于年度运营数据，不是日常统计 | [网易云年报隐私指引](https://y.music.163.com/g/yida/51c3865231a843f2a98a5821d9affdc7) |

### 更正记录

初版文档把"网易云等级听歌量（>60秒 + 去重）"误当成网易云通用播放次数口径。实际：
- **听歌排行 = 重复计数**（听 N 次记 N 次）
- **等级听歌量 = 去重计数**（只用于等级加速）
两者是不同功能，不能混淆。

## 决策（用户明确要求）

**不记录时长，只记录次数：一首歌放完就 +1。**

- 计数时机：`audio.Player` 真正播完（ended）→ +1；**手动切歌/暂停不算**。
- 重复播放同一首歌 → Count 持续累加（重复计数，不是去重）。
- 对齐网易云"听歌排行"的"完整播放才算"口径，但不去重。
- 时长统计**完全去掉**（不做 250ms 进度差、不落 totalSec），省资源。

## 代码落点

- `mygo_output.go`：新增独立 `SetFinishedHook`（与核心 `SetEndedHook` 并列，互不覆盖），播完时两个都调。
- `main.go`：注入统计 hook（本机 ended + 音箱 EndedHook），`mygo.RunOnMain` 切主线程后 `statsPlay +1`。
- `player.go`：`play()` 入口不再计数（之前"点了就算"是错的）。
- `play_stats.go`：只有 Count/LastAt/Source/ID/Title/Artist/Cover，无时长字段。
- `stats_page.go`：显示"累计播放 N 次" + 常听歌曲/歌手（按 Count 排序）。
- 单元测试：`mygo_output_test.go` 验证两个 hook 独立；`play_stats_test.go` 验证重复计数。
