# 开发规范 & 插件开发指南

> 项目：mymusic（主线 `go/` web 版 + `mygo/` 原生版）
> 日期：2026-11-19 ｜ 目录：`docs/development/`

## 0. 总则

- **内核稳定，外围可插**：系统内部是一个稳定内核（播放/队列/缓存/UI 骨架），外围是可插拔插件（音源/歌词/目标/设置）。
- **复用主线**：能复用主线域包/api 就复用，不自创逻辑、不造轮子。
- **插件零耦合**：插件只认接口，不认内核具体类型（依赖反转）。
- **未经同意不改主线 `go/`**：主线代码改动需用户授权（本次插件化重构已获授权）。

## 1. 插件接入形式（第三方如何接插件）

**核心设计（2026-11-19 收敛）：主推编译期注册（形式 A），JS 沙箱（形式 C）已落地；WASM（形式 B）用户已否决，不做。**

### 形式 A：Go 插件包 + 编译期注册（主推，无 cgo）

第三方以 Go 包形式实现插件，编译进主程序。**三步接入**：

```go
// 1. 实现插件接口（按类型选一个：source/lyric/target）
//    音源示例（source.MusicSource）
package mysource

import "mymusic-mygo/source"

type MySource struct{}

func (MySource) Name() string { return "mysource" }
func (MySource) Search(kw string, page, size int) ([]source.Song, int, error) {
    // 搜索逻辑（可复用主线 music 域）
}
func (MySource) GetStream(id string, q int) (*source.Stream, error) {
    // 取流逻辑
}
func (MySource) GetLyric(id string, kw []string, sid int) ([]source.LyricLine, error) {
    // 歌词逻辑
}

// 2. init() 里注册自己
func init() { plugin.RegisterSource(MySource{}) }
```

```go
// 3. 主程序空导入启用（main.go 或独立 register.go）
import _ "mymusic-mygo/plugins/mysource"
```

**优点**：类型安全、编译期验证（`var _ source.MusicSource = (*MySource)(nil)`）、零运行时开销、跨平台（含 WASM/安卓）、无 cgo。
**缺点**：第三方需跟主程序一起编译（不能独立分发二进制）。

### 形式 B：WASM 动态插件（❌ 已否决，不做）

第三方用 TinyGo/Rust 编译成 `.wasm`，运行时用 wazero 沙箱加载。**用户 2026-11-19 明确否决：不需要。**

> **否决理由**：WASM 是沙箱，默认无网络/文件系统/UI，给音源/歌词/目标这类需要系统能力的插件上 WASM = 写大量宿主桥接，投入产出比极低；仅适合纯计算（EQ/音效），而音效本身也已被否决（见 §2）。且 WASM 是 TinyGo（Go 子集），插件能力受限。

### 形式 C：JS 沙箱插件（✅ 已落地，sobek）

第三方写单个 `plugin.js`，宿主用 **sobek（纯 Go JS 引擎，无外部运行时）** 加载，扫描 `plugins/*/plugin.js` 自动启用。**一个 `.js` 文件就能加新音源/歌词，主程序不重编、跨平台（含安卓）、无 cgo、沙箱安全（超时/白名单/JSON 边界）。**

```go
// main.go 启动：plugin.LoadFromDir("plugins") 扫描加载注册
```

```js
// plugins/netease/plugin.js —— 网易云音源示例（真实）
var meta = { apiVersion: 1, key: "netease", capabilities: ["source"], allowedHosts: ["music.163.com"], order: 20 };
function search(ctx) { /* ctx.host.http(...) 宿主注入，白名单受限 */ }
function getURL(ctx) { /* 取流 */ }
```

**优点**：独立分发（上传 .js 即用）、不重编主程序、跨平台（sobek 纯 Go）、沙箱安全（学 new-api 三层：超时/并发上限 + allowedHosts 白名单 + 数据只走 JSON）、插件设置系统统一管理（`host.config.get/set`）。
**缺点**：插件写 JS 非 Go；性能是控制面级（单次调用 ~2µs，不适合音频热路径）。

> **决策**：形式 A（编译期注册，Go 插件）为内置/生态内主推；形式 C（JS 沙箱）为第三方动态插件通道。**新增插件类型不改核心逻辑**——注册表是 map+接口+init 的通用模式。

### 插件元数据（插件页展示，可选但推荐）

```go
plugin.RegisterInfo(plugin.Info{
    Name: "mysource", Type: "source", Icon: "bilibili",
    Version: "1.0", Desc: "我的音源", Order: 70, // Order 固定展示顺序（防跳动）
})
```

### 插件启用/禁用（插件页开关）

```go
plugin.SetEnabled("source", "mysource", true)
plugin.IsEnabled("source", "mysource") // true=启用（默认）
```

## 2. 插件类型（当前 4 类；音效/EQ 已否决，不做）

| 类型 | 接口 | 注册 API | 说明 |
|---|---|---|---|
| **音源** | `source.MusicSource` | `plugin.RegisterSource` | 搜索/取流/歌词（B站/网易云 JS 实现） |
| **歌词** | `lyric.Provider` | `plugin.RegisterLyric` | 词源 Fetch（网易云实现） |
| **目标** | `target.Target` | `plugin.RegisterTarget` | 投送设备（本机/DLNA/蓝牙/音箱） |
| **目标面板** | `plugin.TargetPanel` | `plugin.RegisterTargetPanel` | 目标页区块（依赖反转 TargetPanelHost） |
| **设置** | `plugin.Setting` | `plugin.RegisterSettings` | 插件设置声明（系统统一管理 SettingStore） |

**音效/EQ（Effect）❌ 已否决（2026-11-19）**：主线（web）音频是浏览器 `HTMLAudio` + 音量，**没有 EQ/音效处理**。mygo 做音效 = 脱离主线自创一套 PCM 效果链架构（违背“复用主线/别造轮子”），且非核心功能。**不做。**

**新增插件类型**只需：定义接口 → 加一个 `RegisterXxx` → 插件页加 `pluginGroup(c, "标题", "类型")`。**核心逻辑零改动**。

## 3. 稳定链路 API（`plugin.Link`）

任何端（桌面/安卓/WASM）基于 `Link` 驱动核心，不碰 UI。`linkCore` 只持 playback 状态机 + 注册表，可独立 `NewLink(pb)` 构造。

```go
link := NewLink(pb)          // 注入播放核心
songs, total, _ := link.Search("周杰伦", 1, 40)  // 搜索
link.Play(songs[0].ID, songs[0].Title, "")       // 本机播放
link.Play(songs[0].ID, songs[0].Title, "speaker/did") // 投送音箱
link.Pause() / link.Resume() / link.Stop() / link.Seek(30)
targets := link.Targets()    // 可用目标列表
lyrics, _ := link.Lyric([]string{"歌名"}, 0)     // 歌词
```

## 5. 编码规范

### Go
- **无 cgo**（WASM/安卓兼容，插件不依赖动态加载）
- 错误处理：**非关键路径 `_ =` 吞错**，关键路径 `if err != nil` 真处理
- 接口方法用编译期断言验证实现（`var _ interface = (*T)(nil)`）
- map 遍历如需固定顺序：显式排序（防 UI 条目跳动），加 `Order` 字段
- **不造轮子**：能复用主线域包就复用（playback/lyriccache/cast/speaker/cache）

### UI（MyGo）
- 复用原语：`navTab`/`chip`/`switchToggle`/`statusBadge`/`setRow*`
- 形状差异化：播放=圆、其他=方；胶囊仅搜索框/搜索按钮/navTab/switchToggle
- **无动画**；**双击播放**；原生右键菜单
- 标题字号统一（主标题 20px），页面内不重复导航项名

### 测试
- 契约测试：接口编译期断言 + 失败路径（`plugin`/`source`/`lyric`/`target`/`link`）
- 注册表测试用**假实现**注册（不依赖 app 初始化）
- 主线 `go/`：golangci-lint 清零（errcheck/unused/gosimple/staticcheck/ineffassign/bodyclose）
- mygo：`go vet`（golangci-lint v1.64.8 对 go1.27 不兼容，用 vet）

## 6. 构建/测试/运行命令

```bash
cd mygo
# 构建（native tag）
GOFLAGS="-mod=mod -tags=native" GOPROXY=https://goproxy.cn,direct go build -o /tmp/mygo-fix .
# 测试
GOFLAGS="-mod=mod -tags=native" GOPROXY=https://goproxy.cn,direct go test -tags native ./...
# 静态检查
GOFLAGS="-mod=mod -tags=native" GOPROXY=https://goproxy.cn,direct go vet ./...
# 运行（后台长驻必须 setsid nohup 防工具超时杀进程）
pkill -f "^/tmp/mygo-fix"; DISPLAY=:0 setsid nohup /tmp/mygo-fix > /tmp/mygo-fix.log 2>&1 </dev/null & disown

cd ../go   # 主线
export PATH=$PATH:/home/a1/go/bin
GOFLAGS="-mod=mod -tags=native" GOPROXY=https://goproxy.cn,direct timeout 280 golangci-lint run ./...
```
